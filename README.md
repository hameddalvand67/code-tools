# کدتولز

پلتفرم ساده برای ذخیره دستورات، قطعه‌کدها و **فلوهای قابل‌ترکیب**.

هر «عمل» یک درخت است. می‌توانید همان درخت را داخل فلوهای دیگر استفاده کنید؛ لازم نیست دستور را دوباره در ورد بنویسید.

## اجرا

```bash
cd /opt/apps/code-tools
docker compose up --build -d
```

سایت: `http://SERVER:8088`  
ورود مدیریت: همان آدرس `/login/`  
پنل ادمین: `/admin/`

مشاهده و کپی برای همه آزاد است. ساخت و ویرایش نیاز به ورود دارد.
